# 🎯 Control System Learnings

This project provided a practical understanding of PID control that extends beyond theoretical study.

### Proportional Gain (Kp)

Increasing Kp:

- Faster response
- Larger oscillations if excessive

### Integral Gain (Ki)

Increasing Ki:

- Eliminates steady-state error
- Can increase overshoot
- May introduce oscillations if too large

### Derivative Gain (Kd)

Increasing Kd:

- Improves damping
- Reduces overshoot
- Increases stability

# 📈 Testing Insights

Experimental testing demonstrated that system performance depends on multiple interacting factors.

| Observation | Engineering Insight |
|------------|----------------------|
| Servo jitter | Often caused by unstable power or poor tuning |
| Sensor fluctuations | Filtering improves measurement quality |
| Oscillations | Usually indicate excessive proportional gain |
| Slow response | May require higher proportional gain |
| Position drift | Often related to integral tuning |

# 🎓 Recommendations for Future Students

If you plan to build a similar project:

1. Understand PID theory before writing code.
2. Assemble the mechanical system carefully.
3. Verify every electrical connection before powering the circuit.
4. Test each subsystem independently.
5. Tune one PID parameter at a time.
6. Document every modification.
7. Record experimental observations.
8. Never skip calibration.
