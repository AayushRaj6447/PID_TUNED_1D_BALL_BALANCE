# 📖 Overview

A key objective of this project was to develop a functional PID-controlled ball balance system while maintaining a reasonable project budget.

Components were selected based on the following criteria:

- Performance
- Availability
- Cost
- Reliability
- Ease of replacement
- Educational value

Where multiple options existed, preference was given to components that offered the best balance between functionality and affordability.

# 🚧 Procurement Challenges

During procurement, several practical challenges were encountered:

- Limited local availability of specialized sensors
- Price differences across vendors
- Shipping delays
- Component compatibility verification
- Variation in product quality

---

# 💡 Cost Optimisation Opportunities

Future versions of the project can reduce costs by:

- Designing a custom PCB
- Bulk purchasing components
- Reusing laboratory hardware
- Fabricating mechanical parts in-house
- Standardising fasteners and mounting hardware

# 📌 Procurement Summary

The procurement process successfully balanced cost, availability, and performance. The selected components fulfilled all functional requirements while keeping the project economical and suitable for educational use.

The modular component selection also ensures that individual parts can be replaced or upgraded without significant redesign.

---

> [!NOTE]
>
> Maintain invoices and purchase records for future maintenance, warranty claims, and cost verification.

> [!TIP]
>
> Before ordering electronic components, verify voltage ratings, dimensions, and connector compatibility to avoid unnecessary delays.

> [!IMPORTANT]
>
> Avoid selecting components solely based on the lowest price. Reliability and compatibility often have a greater impact on overall project success.
